# How the six scores work

Five are grades, shown as a percentage to one decimal and a letter (A is 90.0% and up, B 80.0%, C 70.0%, D 60.0%, F below 60.0%); the letter comes from the one-decimal percentage. There are no indexes: every part of a grade is a percentage too, and Legal Trouble is the percentage points its cases take off. Ideology is a position, not a grade. Missing data never counts as zero: a score without enough evidence shows "Not graded".
