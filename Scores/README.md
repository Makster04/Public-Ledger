# How the six scores work

Five are grades, shown as a percentage and a letter (A is 90% and up, B 80%, C 70%, D 60%, F below 60%). The 0–100 indexes inside them show as percentages too, except Legal Trouble, which is points. Ideology is a position, not a grade. Missing data never counts as zero: a score without enough evidence shows "Not graded".

1. [Ideology](01_IDEOLOGY.md) (a position, not a grade)
2. [Keeps Their Word](02_KEEPS_THEIR_WORD.md)
3. [Shows Up](03_SHOWS_UP.md)
4. [Big Money Independence](04_BIG_MONEY_INDEPENDENCE.md)
5. [Plays by the Rules](05_PLAYS_BY_THE_RULES.md)
6. [People First](06_PEOPLE_FIRST.md)
